# 🚨 AlertUp — Frontend

React frontend for AlertUp — a platform to create, manage, and receive real-time alerts and notifications.

> ✍️ Built at approximately **age 15** (2025-2026)

---

## Features

- 🔔 Create and manage custom alerts
- 📋 Dashboard view of active/past alerts
- 🔐 Login / Register with JWT auth
- 📱 Responsive design

---

## Stack

- **Framework:** React
- **State management:** Context API / Redux *(update as needed)*
- **HTTP client:** Axios
- **Styling:** Tailwind CSS / CSS Modules
